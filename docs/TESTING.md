# 测试

在仓库根目录运行：

```sh
python3 tools/run_tests.py
```

运行器使用 `lua`；可以用 `--lua /path/to/lua` 指定 Lua 5.4。检测到 `luac` 时检查模组与测试脚本语法，也可用 `--luac /path/to/luac` 指定。

49 个 Lua 测试文件中，44 项使用本仓库的模拟环境，5 项需要从自己安装的 Build 40420 游戏提取 GUI 源文件：

```sh
python3 tools/run_tests.py --game-gui /path/to/extracted/gui/main
```

该目录须包含 `react.lua`、`stylesheetutil.lua`，且保留相对路径 `../../scripts/mat4.tl`。相关文件不在仓库或安装包中分发。缺少此参数时，运行器打印五项 SKIP；提供了无效目录时直接报错，不将它们计为通过。

覆盖站序与折返、合并连通性与方向、分叉坐标和轨道分层、其他分支白点、标号设置与批量提交、换乘分组与导航、点选关联、持久化以及读取／生命周期预算。

## 实机验收

- 未保存语言选项的存档首次打开应显示英文，包括窗口标题和入口提示；明确保存中文或英文后，重载仍保留选择。检查地铁 1、8、10、18 等编号：字体更大，圆形外框大小不变，前后缀与长编号不溢出。

- 拖动线路图入口到地图的亮、暗背景上，检查按钮周围及下方没有长条阴影或矩形残留；悬停、打开／关闭设置后再检查。按钮主体和拖动条保持可见，设置窗口仍有原生背景和边框。

- 在目录首页点击 English，确认已打开的窗口标题、入口按钮悬停提示及拖动条提示立即切换为英文，不需要关闭窗口或再次点击入口；点击中文切回。确认目录、线路设置、公交编号、关联车站及提示均跟随语言。线路／站点／城市名和自定义前后缀保持原文，窄窗口按钮不重叠。保存并完整重载确认语言保持；语言切换不能重置闪烁选项。

- 在两条同号线路的各个成员和往返方向检查：共同站点只画一次，分叉接入正确，不经过的分支站点内部为白色，站点不被轨道遮住。
- 查看 RER、Metro、电车的左右分叉及汇合：横线与斜线通过相切圆弧连接，终端有圆头，站点不移动；电车中间细纹连续。分别检查第一人称与静态图、窄视口及多分支。
- 开关闪烁、到达终点并自动折返，确认当前路径的已过站和下一站正确。
- 打开目录，确认首页入口为「线路设置」，点击后显示「公交线路编号一键配置」按钮与「黄灯闪烁：开启／关闭」开关；黄灯项没有辅助说明或悬停提示。目录首页不再显示这两项。公交配置的启用项应为按钮，默认关闭。
- 搜索公交、点击线路及换乘、返回目录，确认图和状态不继续累积。
- 进入车辆第一人称后，线路图设置按钮应隐藏；退出后应在原位置恢复。暂停菜单中仍应隐藏，底部站点图保持正常。
- 普通视角中入口默认位于右上角，与左上角图层按钮处于同一行、同样大小；悬停／打开后不能放大或移动。按住图标上沿短横条拖动，点击主体应只开关设置。打开设置后标题下面不应出现大块空白。检查拖动至四边、改变窗口大小、切换 UI 缩放、关闭其他窗口后入口仍可用，关闭并重开设置不能重置入口位置。另一个模组替换 `FreeCamOptions` 后，入口仍可独立打开；其第一人称 HUD 的兼容性需另测。
- 打开各类型线路图，点击顶部图钉，确认设置关闭且地图定位到相应线路；第一人称中应先退出驾驶视角。换乘跳转后定位跳转到的线路，合并图定位当前打开的实际成员。已删除线路应显示提示，不能跳转到其他实体。
- 编辑前缀／编号／后缀，筛选隐藏部分修改后全部应用；保存并重载确认配置保留。
- 进出第一人称后，在同存档、同车辆、同视角与速度下对照启用／禁用模组的 FPS、内存和保存耗时。

Lua 测试和离线组件树不运行游戏 C++ GUI，不能替代这些实机检查。

`test_track_curves.lua` 检查圆弧相切、连续性、端点、窄视口和回环，限制每个拐角最多 12 段；原版样式解析器检查柔化边缘的遮罩和旋转选择器确实匹配。遮罩由 `tools/make_track_mask.py` 离线生成，所有线路共用，游戏运行时不生成图片。

双语测试检查全部受控翻译键、保存事件的独立选项合并、首次点击及失败回退、重开窗口、英文省略站点与用户数据保留。原版 React 测试检查已挂载标题、入口与拖动提示的语言订阅，只重绘收到状态通知的组件；删除订阅会使对应测试失败。语言切换后仍直接返回 Window，并验证窄窗口搜索栏。对齐检查覆盖中文／英文各六种视口宽度。

`test_real_react_entry.lua` 使用原版 React 替换表和插件发现逻辑，复现另一个模组覆盖相机组件后入口消失的情形，再检查独立扩展点仍能创建原生可移动入口；同时检查右上角初始化参数、独立视口测量、零空闲查询、卸载移除窗口和取消待打开任务。删除延迟挂载中的存活保护会使测试失败。它不模拟 C++ 的实际绘制或鼠标拖动。

入口外壳透明检查叠加游戏原版 Window／no-close-button 样式与模组样式，验证背景、边框、阴影贴图被清空，且不会影响设置窗口。
