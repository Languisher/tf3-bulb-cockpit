# Interface languages

Choose a language in the directory homepage’s native selector. The default is English; existing `en` and `zh` preferences remain valid. Save the game to keep the preference in that save. Selection immediately updates the mod’s title, button hints and page content. Game line, stop and city names and user-entered badges are never translated.

`Train` and `RER` are category names and remain recognizable in every language. Unconfigured game railways use Train. RER is an explicit display choice. The old screenshots predate this split.

## Translation maintenance

The stable source-message keys and English fallback live in `mod/content/gui/bulb_cockpit/localization.lua`. Simplified Chinese uses the source messages. The other twelve catalogs are UTF-8 Lua tables in `locales/<code>.lua`, with 146 messages each. These are interface translations; wording and native font appearance should also be reviewed in-game by speakers of the language.

Keep `%d` and `%s` parameters in their original order. Parameter values are game data and must remain untouched. Missing entries fall back to English, then the original source message. The selector always shows each language’s native name using the Unicode compatibility font so users can recover from an accidental selection.

Only selected catalogs are loaded, at most once per language and Lua module lifetime. There is no online translation service, file polling, vehicle query or new timer. Existing English / Simplified Chinese controls retain their native scaled font; new languages use the game’s Unicode compatibility font in setting labels. Translated HUD annotations also use Unicode compatibility, while line badges and station names retain their existing bold native rendering.

To add a language:

1. Add its lowercase code and native name to `I.locales` and provide a full catalog matching the English keys.
2. Add the code to the small event-validation lists in GUI `aliases.lua` and simulation `bulb_aliases.script.lua`. The simulation does not load GUI dictionaries.
3. Update the language count and normalization examples in `tests/test_i18n.lua`. That test exercises both validation lists through actual save commands.
4. Run `tools/run_tests.py` with Lua 5.4 and, when available, the extracted game GUI. The selector and six-width layout tests enumerate the entire registry automatically.
5. Check dropdown placement, long labels, diacritics and CJK glyphs in-game, including an English-language game installation, and verify preference persistence after saving and reloading.
